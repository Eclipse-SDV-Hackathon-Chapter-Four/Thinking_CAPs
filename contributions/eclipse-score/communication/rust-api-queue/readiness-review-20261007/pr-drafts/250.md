# Support typed Any discovery in Rust

Draft proposal; engineering acceptance and merge readiness remain pending.

Replaces the Any panic with native same-interface wildcard discovery and fallible registration resolution. Async discovery returns one latest snapshot, can remain pending until an offer, and owns an early stop guard even if the future is never polled. This packet preserves the implementation unchanged.

Related to eclipse-score/communication#250. Do not close the issue until the
scope and acceptance criteria below are resolved.
