# Actual native P704 payload preflight

Two actual pinned Fabro API workflows transmitted the exact prepared baseline and
optimized prompts to a loopback refusal endpoint. Both exported reports and exited
without human nodes. No upstream transport, real credential, candidate reply, source
application or native functional build/test was supplied. Private server/run state
stays internal; empty targets and analysis/tool scratch use shared external storage.

The observed native requests contain 13 generic tool declarations. Existing explicit
tool projection removes them; the messages remain intact. Initial projected requests
are 23,802/20,560 bytes. Native wrapper bytes differ from the earlier reconstruction;
all original requests, stage identities and wrapper differences are retained.

The native emitter supplies `reasoning_effort=low` and omits non-thinking/JSON settings.
The measured gap is fixed by an optional, exact operator-pinned `request_parameters`
profile in activation/request projection. Only the complete Flash non-thinking JSON
profile is accepted; partial controls, other providers/models and additional overrides
are refused. Instructions without this field retain their previous behavior. Source
messages, output/model ceilings, usage accounting and engineering admission stay bound.

Applying the proposed explicit profile to actual captured native requests produces
23,875/20,633 bytes, with 125/3,367 bytes of headroom under the unchanged 24,000-byte
guard. See [projection results](profile-projection-results.json) and
[the offline report](review-report.md). These profile-projected payloads are measured
locally, not transmitted to DeepSeek. Seventeen new parameter cases, including real
loopback JSON/SSE wire and added-byte limit refusals, pass in the 174-case scoped suite.
Ruff and mypy pass. Initial test-status assertion and unqualified-Python export failures
are retained. Full repository/package/trace results are in `validation-results.json`.

Owned endpoints/server are closed. Usage, actual bills and whole-task savings remain
null. All 12 previous packets and reviewed T032 subjects are immutable. Two source
files change deliberately, one regression file is added, and the other 303 previous
source/test files retain their hashes. Old test measurements are superseded by fresh
scoped checks for this change. Native scope/QNX/roles, full-stage envelopes and real
operator runtime admission remain pending offline decisions.
