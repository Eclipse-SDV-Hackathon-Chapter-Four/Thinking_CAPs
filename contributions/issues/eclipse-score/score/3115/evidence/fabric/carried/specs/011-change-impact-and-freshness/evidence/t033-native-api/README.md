# Provider-disabled native API binding qualification

Two fresh private Fabro API runs exercise the frozen fabric bindings in actual native
workers. Each initializes the 740-file original P704 archive, refuses cross-run/arm
identity, applies a labeled historical local replay, runs a lightweight fresh collector,
routes the exact protected feedback through native `context_updates`, and refuses the
provider guard before an unanswered human gate. Both actual API projections and all
16 native hook witnesses match the exact bound workers.

The lightweight collector intentionally lacks required native test XML. Its native
command exits with a failed check receipt; feedback retains **missing** and the gate
remains unanswered. This verifies failure/routing behavior, not target correctness.
The previous two 113-case target checks remain unchanged in the US19 packet. No model
prompt is sent; provider response capture/usage and actual agent consumption remain
unqualified. Native impact/expected-set closure, QNX, B1–B5 and T033 acceptance remain
pending. No PR, publishing or paid model request is made.

The isolated server imports no provider credential and points DeepSeek at a localhost
denial endpoint, which receives zero requests. Native API usage is zero. All owned
runs are canceled, private workers stopped, and the new server shut down; the unrelated
existing Fabro service is untouched. Credentials/private server state stay internal;
source archives, collectors, analysis and caches use the bound Linux build volume. The
API-owned worker belongs to Fabro's private server scratch; collector copies stay on
the selected external volume.

the isolated PATH omitted `losetup`, required to validate the registered Linux image.

run-specific HEAD and rejects links/active hooks; it excludes only that validated
engine directory from source hashing and leaves unrelated files protected. Native
checkpoint IDs are not native S-CORE baseline IDs. Regression cases cover metadata
and source tampering, and local workers cannot use the exception.
