## Design, ownership and failure analysis

The registry belongs to an independently built runtime; clones share it. Offered service keys include interface ID; event keys additionally include event identifier and TypeId. Providers share a registration guard: unoffer removes that registration and last-handle Drop cleans it up. Subscriptions register weak references, own independent queues and remove their own registration on unsubscribe/drop. There is no retained replay before subscription and no global registry cross-test contamination.

Native CommData/Reloc requires Send, Unpin and 'static, not Clone or Sync. Ownership moves to one subscriber. Multiple subscribers require register_cloneable_data<T: CommData + Clone>(); missing registration returns the existing EventPublishFailed error before any delivery. All cloning completes before enqueueing, outside locks. Queue overflow discards oldest. Samples have IDs assigned under the queue lock to preserve per-subscription reception order; finite usize counter wrap is an untested long-run limitation of this test runtime.

Receive validates bounds and container capacity before draining; foreign subscription samples are rejected without consuming them. Native SampleContainer gains a capacity accessor without changing its representation. Async receive registers its waker before probing the queue, returns retained data on cancellation and clears wake registration when dropped. Stream stays pending on empty queue and wakes on later data. Overlapping async receives deliberately panic after releasing the lock so this contract error does not poison the subscription. Synchronous callers can still compete for queue items and must coordinate externally.

This test runtime allocates on the heap (maps, boxes, queues, fan-out buffers), uses std mutexes and can panic on allocation/poison/invariant failure. It has no bounded real-time or IPC safety claim. The only unsafe payload operation is native assume_init with the caller's existing initialization obligation. Publication/unsubscribe races can retain a queue snapshot until that operation completes; ownership stays valid and cleanup follows. Executor wake calls and payload eviction destructors run outside locks. Discovery async is a snapshot, not the separate #1261 live discovery feature.
