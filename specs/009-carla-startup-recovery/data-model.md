# Physical campaign evidence
Readiness attempt: monotonic timestamp, RPC error; fresh client per attempt. Ready world:
actual server/client version and map, owned process and actor identity. Simulation sample:
frame/elapsed simulation seconds, physical speed, VCU engagement, native request received,
VCU throttle command and actor applied throttle/brake. Native diagnostic timestamps remain
Linux monotonic; no simulation/host or cross-host clock equivalence is inferred.
